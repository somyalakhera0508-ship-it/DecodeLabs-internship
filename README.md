# Rule-Based AI Chatbot in C++

## Project Overview
This project is a simple Rule-Based AI Chatbot developed using C++. The chatbot interacts with users by responding to predefined inputs using conditional statements. It demonstrates basic concepts of Artificial Intelligence, user interaction, and decision-making logic.

## Features
- Greets the user.
- Responds to predefined questions.
- Handles multiple user inputs.
- Continues conversation until the user enters "bye".
- Simple and beginner-friendly implementation.

## Technologies Used
- C++
- Visual Studio Code

## How It Works
The chatbot takes user input and checks it against predefined rules using if-else statements. Based on the input, it returns an appropriate response.

### Sample Conversation

User: hi
Bot: Hello! Nice to meet you.

User: how are you
Bot: I am fine. Thanks for asking!

User: bye
Bot: Goodbye! Have a great day.
